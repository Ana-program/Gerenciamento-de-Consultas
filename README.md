# Gerenciamento de Consultas 

API RESTful desenvolvida em Java com Spring Boot para gerenciamento de consultas médicas. Permite o cadastro, busca e exclusão de médicos, pacientes e consultas.

## Funcionalidades

- Cadastro, listagem e exclusão de médicos  
- Cadastro, listagem e exclusão de pacientes  
- Cadastro, listagem e exclusão de consultas
